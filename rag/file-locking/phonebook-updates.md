# 電話帳更新のファイルロック

出典: [filelock公式資料](https://py-filelock.readthedocs.io/en/latest/)と、導入したライブラリの型・実装、[電話帳の実装](../../src/jev_bookmarks/phonebook.py)。取得日: 2026-10-02。確度: 公開仕様とMacの競合再現を確認済み。

`FileLock` はプロセス間の排他を提供し、WindowsとUnixにネイティブの実装を持つ。電話帳の形式はJSONのまま保ち、更新の読取からファイル置換までを同じロックで囲む。読み取りは原子的に置換されたファイルを読むため、更新のロックを取らない。

導入した型で `fallback_to_soft` を確認し、無効にした。OSのネイティブロックを使えない時は、そのエラーを返す。依存の条件は [pyproject.toml](../../pyproject.toml) と `uv.lock` が正本。

原子的な置換だけでは同時更新の消失を防げない。2件が同じ旧状態を読めば、どちらも正常に置換でき、最後のファイルには片方しか残らない。更新全体の直列化後、保存同士と保存・削除の競合を確認した。

原文の短い引用は [raw/filelock.md](raw/filelock.md) に置く。
